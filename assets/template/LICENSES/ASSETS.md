# Bundled open-source assets

All assets in this folder are local files. Templates generated by this skill
never request a font, icon, texture, model or script from the network.

## Fonts

Bundled from Fontsource 5.3.0 distributions of the original Google Fonts projects:

| Local file | Upstream family | License |
| --- | --- | --- |
| `fonts/space-grotesk-latin-wght-normal.woff2` | Space Grotesk | SIL Open Font License 1.1 (`OFL-space-grotesk.txt`) |
| `fonts/newsreader-latin-wght-normal.woff2` | Newsreader | SIL Open Font License 1.1 (`OFL-newsreader.txt`) |
| `fonts/manrope-latin-wght-normal.woff2` | Manrope | SIL Open Font License 1.1 (`OFL-manrope.txt`) |
| `fonts/ibm-plex-mono-latin-400-normal.woff2` | IBM Plex Mono | SIL Open Font License 1.1 (`OFL-ibm-plex-mono.txt`) |
| `fonts/ibm-plex-mono-latin-500-normal.woff2` | IBM Plex Mono | SIL Open Font License 1.1 (`OFL-ibm-plex-mono.txt`) |

The Latin subsets are intentional: Chinese and other CJK glyphs fall back to
the operating system's local CJK UI fonts (PingFang SC, Microsoft YaHei,
Noto Sans CJK SC, etc.).

## Icons

The inline SVG symbols in `index.html` are adapted from **Lucide** 1.69.0
(https://lucide.dev), under the ISC License. See `ISC-lucide.txt`.

Icons used: orbit, layers, rotate-ccw, maximize, scan-line, focus, move-3d,
activity, mouse-pointer-2, sparkles, chevron-right, settings-2, gauge.

The symbols remain inline in the document so they work from `file://` without
an extra request or CORS dependency.
